# Keegan's Card Stand

Inventory tracker for a Pokémon card vending stand: look up a card by set and number, see the market price, and record buys and sells.

Live app: https://gleslie271.github.io/keegan-card-inventory/

- Prices come from TCGdex (TCGplayer for English cards, Cardmarket for Japanese).
- Records are saved in the browser on each device (local storage). Use Backup in Settings to move them.
- Photo scanning uses your own Claude API key, entered in Settings. The key stays in that browser and is never stored in this repository.
