Photo scanning

Scanning sends the card photo to Claude, which reads the set code, number and language. It needs a Claude API key from console.anthropic.com. API use is billed there per photo, separately from any Claude subscription, and costs about a cent or less per scan. Set a monthly spending limit in the Console to be safe.

Japanese card prices

Japanese prices come from Cardmarket (Europe) in euros, through TCGdex, and are converted to dollars. They run lower than US prices for many cards, so treat them as a floor and use the eBay button to check.

Sample cards for testing

Adds about 20 real Japanese, Chinese and English cards with made-up buys and sales from three past shows, so the stock, log and reports have something in them. Sample entries are marked and can be removed without touching real ones.

Backup

Everything is saved in this browser on this device only. Download a backup now and then, and use it to move to another phone.
